# Welcome to the bill splitting app

## Friends can't figure out how to read a receipt? This is for you.

Use this app to select a photo of a receipt from your photo library or scan a receipt using your phone's camera.

I built this just for fun utilizing Expo, along with @devinikhiya/react-native-tesseractocr and @react-native-ml-kit/text-recognition for taking photos/using saved images on your device and reading the text from the images.
